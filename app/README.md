# NeuroAlign App

Participant-facing Streamlit app for exploring brain twin matches and regional BAG profiles.

## Run



Opens at http://localhost:8501

## Prerequisites

- Embedding + retriever built (run  through section 8)
-  set in 
-  path set in 

## What it does

1. Participant enters their subject code
2. App loads pre-built FAISS index and finds their brain twins
3. Tab 1 — Brain Twins: shows twin questionnaire profiles + LLM interpretation
4. Tab 2 — Brain Profile: shows network-level BAG bar chart + LLM interpretation
